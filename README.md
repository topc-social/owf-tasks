# OWF tasks

The Open Work Framework's public project repo. OWF is how work happens in the open, in any setting: needs are public, anyone can pick up work, a contribution is a claim with evidence, credit goes to whoever did it, and the record is permanent. Spec: [kamal0808/OWF](https://github.com/kamal0808/OWF).

- [Issues](https://github.com/topc-social/owf-tasks/issues): open tasks. Each issue is one task, and its `neki:N` label is the Neki it earns.
- [`LEDGER.md`](LEDGER.md): who has earned what on OWF.
- Prices come from Neki's [rate card](https://github.com/topc-social/neki-tasks/blob/main/RATE_CARD.md).

## How it works

1. Pick any open issue. Anyone can hand in, and the best hand-in wins.
2. Do the work however you like, including with your own AI.
3. Hand in with a pull request that says `Closes topc-social/owf-tasks#N`, or comment on the issue with a link others can open.
4. Kamal accepts the best hand-in and closes the issue as completed. A workflow then adds the two Neki rows (1% idea, 99% work) to [`LEDGER.md`](LEDGER.md).

## Rules

- Proof must be something others can open.
- Made-up people, answers or numbers earn nothing.
